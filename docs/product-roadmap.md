# Product Roadmap — Bighart Beat

## Vision
Bighart Beat is a playable browser drum machine with a lightweight rhythm-intelligence layer: instrument first, explanation second.

## Phases

1. Repo foundation and master plan.
2. Behavior-preserving v4 app shell.
3. Modular state/audio/UI extraction.
4. Static rhythm-intelligence MVP.
5. Controlled pattern variation.
6. Performance macro and wiki bridge.

## MVP
Playable 6-track × 16-step drum machine with stable transport, pattern banks, mixer, voice editing, FX, import/export, and deterministic rhythm analysis.

## Non-goals
No generative/AI variation, MIDI, live input, cloud sync, audio export, or medical/neuroscience claims in MVP.
