# Mission 001 — Repo Foundation and Master Plan

## Goal
Turn Bighart Beat from loose HTML snapshots into a repo-backed project with a clear roadmap, architecture, and implementation gate.

## Outputs
- `.hermes/agents/*.md` role files
- `docs/MASTER_PLAN.md`
