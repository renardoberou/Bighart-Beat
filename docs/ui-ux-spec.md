# UI/UX Spec — Bighart Beat

Use v4's three-zone studio shell: transport rail, always-visible 6×16 sequencer, scrollable control deck.

## Required UI
- Play/stop, BPM +/-/tap, current step, pattern A–D.
- Track rows: KCK, SNR, HHT, CLP, INP, ETH.
- Voice, Mix, Rhythm, FX, Master sections.
- Compact Rhythm Intelligence chip/panel.

## Mobile decisions
- Avoid double-click as primary mute gesture.
- Keep sequencer visible in portrait.
- Preserve warm dark Resonant Systems visual identity.
- Use labels plus color; do not rely on color only.
